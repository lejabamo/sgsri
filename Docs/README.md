# GitHub Pages - Smart Context Diagram

Este directorio contiene el reporte del Smart Context Diagram de SmartAuditorIA para ser publicado en GitHub Pages.

## 📋 Archivos

- `index.html` - Reporte principal con diagramas Mermaid interactivos
- `assets/` - Imágenes y recursos estáticos

## 🚀 Cómo Habilitar GitHub Pages

### Opción 1: Desde la Interfaz Web de GitHub (Recomendado)

1. Ve a tu repositorio en GitHub: `https://github.com/TU_USUARIO/TU_REPOSITORIO`
2. Haz clic en **Settings** (Configuración)
3. En el menú lateral, busca **Pages** (Páginas)
4. En **Source** (Fuente), selecciona:
   - **Branch**: `evaluation` (o la rama que uses)
   - **Folder**: `/docs`
5. Haz clic en **Save** (Guardar)
6. Espera 1-2 minutos y tu sitio estará disponible en:
   ```
   https://TU_USUARIO.github.io/TU_REPOSITORIO/
   ```

### Opción 2: Usando GitHub Actions (Automático)

Si prefieres automatizar el despliegue, puedes crear un workflow de GitHub Actions.

## 📝 Notas Importantes

- Los diagramas Mermaid se renderizan automáticamente en el navegador
- El sitio es completamente estático (HTML + CSS + JavaScript)
- No requiere servidor backend
- Compatible con todos los navegadores modernos

## 🔧 Personalización

Si necesitas modificar el contenido:
1. Edita `index.html`
2. Haz commit y push a tu repositorio
3. GitHub Pages se actualizará automáticamente

## 📄 Exportar a PDF

El reporte incluye un botón "Exportar a PDF" que permite guardar el documento completo como PDF desde el navegador.
